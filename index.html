About this assessment

Measures how effectively each employee uses AI in real development work — not just coding skill. Every employee built the same solution, and experts scored their actual work at each stage.
1 · Requirement analysis check → 2 · Initial build → 3 · First requirement change → 4 · Second requirement change
Each person's overall score maps to a proficiency level: L1 Aware (0–35) uses AI for basic assistance only, L2 Explorer (36–55) is experimenting with more purposeful habits, L3 Practitioner (56–70) uses AI routinely with context and validation, L4 Integrator (71–85) delegates deliberately and validates systematically across stages, and L5 AI-Native (86–100) designs the whole workflow around AI while retaining judgement and accountability.
Claude usage telemetry was not received for every employee — some worked in tools or sessions outside the tracked environment. Usage-based insights are shown only where telemetry was actually captured, and reflect what the tracked environment recorded, not necessarily all AI work done.
